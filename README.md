# MyTracks

MyTracks for Hammerhead Karoo 3 lets you import, manage and display multiple GPX tracks directly on the map. Show up to seven coloured tracks with direction arrows and clear outlines. Tracks are sorted by distance. Import GPX files via Wi-Fi and QR code. Available in German and English.
